# Яндекс Дзен — Автоматический рабочий процесс

## КОГДА ПРИМЕНЯТЬ
Каждый раз, когда пользователь присылает **новую тему** для статьи — выполнять ВСЕ четыре задания по порядку, без дополнительных уточнений.

---

## ЗАДАНИЕ 1 — СОЗДАНИЕ СТАТЬИ

Ты — система генерации контента для Яндекс Дзена.
Продолжительность должна составлять не менее 20 минут чтения.
Ниша: **Рассказы и истории / Семейные драмы**

### ПРОЦЕСС (строго по ИНСТРУКЦИЯ.md)

**ШАГ 1: Чтение файлов**
Прочитай ВСЕ файлы от начала до конца: ИНСТРУКЦИЯ.md → СТИЛЬ.md → СТРУКТУРА.md → ИСТОЧНИКИ.md
КРИТИЧНО: Не пропускай середину файлов (компенсация Lost in Middle).

**ШАГ 2: Выбор структуры**
Из СТРУКТУРА.md выбери подходящую структуру (А/Б/В/Г) для темы.
Покажи: какую структуру выбрал и почему.

**ШАГ 3: Создание таблиц ДО написания**
Создай таблицы: 2.1 Персонажи, 2.2 Хронология, 2.3 Фоновые факты.
КРИТИЧНО: Все таблицы создаются ДО написания статьи.
Покажи таблицы для проверки.

**ШАГ 4: Написание статьи**
Напиши статью согласно СТИЛЬ.md, выбранной структуре, правилам монетизации Дзена.
КРИТИЧНО: Копируй данные из таблиц — НЕ вычисляй заново.

**ШАГ 5: Верификация**
Проверь статью через таблицы: 2.4, 3.1, 3.2, 3.3, 3.4, 3.5

### ФОРМАТ ВЫВОДА
```
## ВЫБОР СТРУКТУРЫ
[Какую структуру выбрал и почему]

## ТАБЛИЦЫ ДО НАПИСАНИЯ
[Все таблицы заполненные]

## СТАТЬЯ
[Полный текст статьи]

## ВЕРИФИКАЦИЯ
### Таблица 2.4: Запрещённые клише
### Таблица 3.1: Верификация фактов
### Таблица 3.2: Атрибуция цитат
### Таблица 3.3: Чеклист Дзена
### Таблица 3.4: Проверка хронологии
### Таблица 3.5: Повторы

## СТАТУС
✅ Статья готова к публикации
ИЛИ
❌ Найдены ошибки: [список ошибок]
```

## ЗАДАНИЕ 2 — ИСПРАВЛЕНИЕ ОШИБОК (если найдены в Задании 1)

Если в верификации найдены ошибки — сразу исправить.

### ПРОЦЕСС
1. **Анализ ошибок** — для каждой ошибки: какая слабость ИИ привела к ней, какое правило нарушено
2. **Исправление** — согласно ИНСТРУКЦИЯ.md, СТИЛЬ.md, СТРУКТУРА.md
3. **Повторная верификация** — через те же таблицы

### ФОРМАТ ВЫВОДА
```
## АНАЛИЗ ОШИБОК
[Для каждой ошибки: что нарушено, почему возникла]

## ИСПРАВЛЕННАЯ СТАТЬЯ
[Полный текст]

## ПОВТОРНАЯ ВЕРИФИКАЦИЯ
[Результаты проверки]

## СТАТУС
✅ Все ошибки исправлены
ИЛИ
❌ Остались ошибки: [список]
```

## ЗАДАНИЕ 3 — ГЕНЕРАЦИЯ ЗАГОЛОВКОВ

Ты — эксперт по созданию заголовков для Яндекс Дзена.
Ниша: **Рассказы и истории / Семейные драмы**

### ТРЕБОВАНИЯ К ЗАГОЛОВКАМ
- Заголовок раскрывает суть (не кликбейт)
- Без сенсационности, соответствует содержанию
- Привлекает внимание, создаёт любопытство
- Длина: оптимально 40–60 символов, максимум 80 символов

### ФОРМАТ ВЫВОДА
```
1. [Заголовок 1] (X символов)
2. [Заголовок 2] (X символов)
3. [Заголовок 3] (X символов)
4. [Заголовок 4] (X символов)
5. [Заголовок 5] (X символов)

РЕКОМЕНДАЦИЯ: [номер], потому что [краткое объяснение]
```

## ЗАДАНИЕ 4 — ИДЕИ ДЛЯ ОБЛОЖКИ

Ты — эксперт по созданию обложек для Яндекс Дзена.
Ниша: **Рассказы и истории / Семейные драмы**

### ТРЕБОВАНИЯ
- Персонажи русской национальности
- 5 вариантов для статьи
- Реалистичные изображения, персонажи крупнее и ближе к экрану
- Сразу привлекает внимание аудитории
- Нейросеть: **Stable Diffusion** (Вариант А)

### ФОРМАТ ВЫВОДА
Для каждого из 5 вариантов:
- Сцена и композиция
- Эмоция / настроение
- Детали (освещение, цвет, фон)
- Готовый промпт для Stable Diffusion на английском языке
